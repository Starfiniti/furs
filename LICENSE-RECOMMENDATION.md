# License recommendation

This foundation pack recommends Apache License 2.0 for the core SDK and self-hosted service because it is permissive and includes an explicit patent grant.

Before publishing:

- add the full Apache-2.0 license text;
- confirm copyright owner and contributor policy;
- decide whether a CLA or DCO is required;
- isolate the WooCommerce/WordPress adapter under GPL-2.0-or-later where appropriate;
- inventory every dependency and copied/reference implementation;
- preserve required attributions;
- do not copy code from AGPL projects into Apache-licensed packages without compatible licensing permission;
- obtain legal review of the final repository split.
